なにをしているか

SFC にいま何人いるかを Wi-Fi の接続数から数え、 明日の30分ごとの人数を毎朝予報して、その答え合わせを毎日記録しています。

ねらいは帰りのバスの混雑です。バスの混み具合は直接測れませんが、 キャンパスの人数なら数えられます。人数の減り方が分かれば、 「3限終わりのバス停はどれくらい並ぶか」を前もって見積もれるはずです。 そのための第一歩として、まずは人数の予報がどれくらい当たるかを、実データで確かめています。

予報のモデル（勾配ブースティング／LightGBM）は、データが少ないうちは大きく外れます。 外れ具合がデータがたまるにつれてどう変わっていくかも含めて、そのまま公開しています。

しくみ

1. 数える5分ごとに DTC API から建物ごとの Wi-Fi 接続数を取得
2. 補う取れなかった時刻は、あとから過去の値を取り直して埋める
3. 表にする1日 × 30分枠の表に、11個の手がかりと実測をまとめる
4. 学習・予報毎朝4時に LightGBM を学習し直して、その日の人数を予報
5. 答え合わせ夜までの実測と予報を並べて、誤差を記録
列中身
x0130分枠の開始時刻
x02〜x08その日の1〜7限の推定履修人数。いまは教室の定員が手に入らないので、開講している教室1つを 50人 × 0.7 = 35人 として数えています（実質「その時限の授業の数」）
x09曜日（代替授業日は時間割上の曜日）
x10学期の何週目か
x11日の種類（通常・代替授業日・休業日）
yその30分枠の実測（接続数 ÷ 1.5 の平均・人）

このほかに、その時刻に授業中の人数（x12〜x16）も記録しています。 11個だけのモデル（A）と、これを足したモデル（B）、曜日と時刻の平均（比べる相手）を並べて評価します。 くわしくはおまかせ予報の戦略へ。

データについて

  • 人数・時間割・学事暦・湘南台行きの時刻表は、DTC API（api.dtc.wide.ad.jp） の公開データです。表示もその公開範囲に合わせています。
  • DTC API には教室の定員が無いので、推定履修人数（x02〜x08）は教室1つを35人とした粗い値です。
  • ためた表と予報は データの一覧 からダウンロードできます（CSV）。
  • Wi-Fi の接続数は端末の数で、人数そのものではありません。1人あたり1.5台として割っています。
